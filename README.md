# Credex AI Spend Audit

AI-powered spend auditing platform built with Next.js, Tailwind CSS, and Supabase.

## Features
- AI tool spend tracking
- Monthly & annual savings calculations
- Dynamic recommendations
- Multi-tool support
- Supabase database integration
- Responsive modern UI

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
